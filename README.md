# mcp-termination-assessment

CISC-W'26 포스터 논문 「원격 MCP 서비스 종료 시 권한 회수의 구조적 한계 및 종료 판정 기준 정립」의 실측 코드와 결과 데이터.

논문 원고·그림·학회 양식은 이 저장소에 두지 않았다. 코드와 재현에 필요한 결과만 담는다.

## 구성

| 경로 | 내용 |
|---|---|
| `testbed/` | 로컬 테스트베드와 실험 E1~E3 (표준 라이브러리만 사용) |
| `survey/` | 공식 레지스트리 기반 원격 MCP 서비스 인가 메타데이터 조사 |
| `tools/` | 원고 조판 보조 스크립트 (재현과 무관, 아래 참조) |

## 1. 테스트베드 실험 (`testbed/`)

상위 인가 서버, 원격 MCP 서버, 하위 인가 서버, 하위 문서 저장소를 로컬(127.0.0.1)에 띄워 세 가지 주장을 측정한다.

| 실험 | 측정 대상 |
|---|---|
| E1 | 상태 비저장 접근 토큰 폐기 후 잔존 접근 구간 |
| E2 | 세션 종료 요청(HTTP DELETE) 거부(405) 이후 세션 존속 |
| E3 | 상위 토큰 폐기·조사 확인 이후 하위 위임 자격을 통한 자원 접근 성립 |

```bash
cd testbed
python run_experiments.py 5     # 반복 횟수, 결과는 results.json
```

포트 9101~9104를 사용한다. 서명 키는 모두 테스트용 고정 문자열이며 실제 비밀값이 아니다. 동봉된 `results.json`은 5회 반복 결과다.

## 2. 인가 메타데이터 조사 (`survey/`)

MCP 공식 레지스트리를 표본 프레임으로 삼아 원격 호스트의 RFC 8414 / RFC 9728 공개 메타데이터만 조회한다. 호스트당 GET 최대 2회이며 인증 시도나 상태 변경 요청은 하지 않는다. 실행하면 외부 호스트 약 9천 곳에 요청이 나가므로 의도한 경우에만 돌릴 것.

```bash
cd survey
python rerun_survey_pipeline.py        # 전체 재실행 (collect -> survey -> analyze)
python rerun_survey_pipeline.py 500    # 호스트 수 제한(시험용)
```

- 재실행 결과는 `rerun_YYYYMMDD_HHMMSS/`에 저장되어 원본을 덮어쓰지 않는다.
- 동봉 데이터: `survey_results.json`(호스트별 결과 8,951건), `survey_summary.json`(집계).
- 레지스트리 원본 덤프(`registry_raw.json` 약 123MB 등)는 용량 때문에 제외했다. `collect.py`가 다시 만든다.
- 레지스트리 내용은 시간이 지나면 바뀌므로 재실행 수치는 논문 수치와 다를 수 있다.

## 3. 조판 보조 (`tools/`)

`render.py`(PDF 미리보기), `to_docx.py`(DOCX 변환)는 논문 원고를 학회 양식에 맞추려고 쓴 스크립트다. 원고 `paper.md`와 그림, 윈도우 글꼴(바탕, 맑은 고딕)이 필요하며 원고는 이 저장소에 없다. 연구 재현과는 무관하다. `PyMuPDF`, `python-docx` 필요.

## 환경

Python 3.12. 테스트베드와 조사 코드는 표준 라이브러리만 쓴다.
